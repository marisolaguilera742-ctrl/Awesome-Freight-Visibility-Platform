Cree un repositorio en GitHub para almacenar el código, realizar un seguimiento de su historial y compilar un proyecto de software que pueda compartir.

En este tutorial, creará el repositorio que usará en esta serie. Creará un proyecto de software pequeño denominado `stargazers-log`. Al final del recorrido, planeará el trabajo, escribirá código, revisará los cambios e implementará el código en un sitio web activo.

`stargazers-log` es un sitio web sencillo que hace un seguimiento de los repositorios que has marcado con una estrella y los muestra. Le ayuda a crear un catálogo personal de herramientas y ejemplos de código que le interesan. Marcar repositorios con una estrella también te ayuda a guardar proyectos para más tarde y a mostrar tu aprecio a las personas que los mantienen.

> \[!NOTE]
> A medida que avance en esta serie, si usa Nube de GitHub Enterprise con residencia de datos o GitHub Enterprise Server, deberá sustituir las referencias y los enlaces a GitHub.com por la URL específica de su empresa.

## Prerequisites

* Una cuenta en GitHub. Para registrarse, vaya a [https://github.com/signup](https://github.com/signup?ref_product=github\&ref_type=engagement\&ref_style=text).

Si usa Enterprise Managed Users o GitHub Enterprise Server, póngase en contacto con su empresa o administrador de sitio para obtener información sobre su cuenta en GitHub Enterprise.

## ¿Qué es un repositorio?

Un repositorio es donde se conservan el código y los archivos de un proyecto de software en GitHub. Almacena los archivos, realiza un seguimiento de cada cambio como confirmación y proporciona a los colaboradores un lugar compartido para trabajar. La mayoría de los proyectos de software, desde una sola página web a una aplicación grande, residen en su propio repositorio.

## Creación del repositorio

Siga estos pasos para crear el repositorio de esta serie.

1. En la esquina superior derecha de cualquier página de GitHub, seleccione <svg version="1.1" width="16" height="16" viewBox="0 0 16 16" class="octicon octicon-plus" aria-label="Create new" role="img"><path d="M7.75 2a.75.75 0 0 1 .75.75V7h4.25a.75.75 0 0 1 0 1.5H8.5v4.25a.75.75 0 0 1-1.5 0V8.5H2.75a.75.75 0 0 1 0-1.5H7V2.75A.75.75 0 0 1 7.75 2Z"></path></svg>y haga clic en **Nuevo repositorio**.

   Como alternativa, vaya a la [nueva página del repositorio en GitHub.com](https://github.com/new?ref_product=github\&ref_type=engagement\&ref_style=text) para abrir el nuevo formulario de repositorio directamente.

2. Use el menú desplegable **Propietario** para seleccionar su cuenta personal para poseer el repositorio.

3. En el campo **Nombre del repositorio** , escriba `stargazers-log`.

4. En el campo **Descripción**, escriba una breve descripción, como «Un registro de los repositorios que he marcado con una estrella».

5. Use el menú desplegable **Elegir visibilidad** para seleccionar **Público** para que pueda publicar el proyecto de software en un sitio activo más adelante en esta serie.

6. Seleccione **Añadir README**. Esto proporciona al repositorio un archivo inicial y un lugar para describir el proyecto de software.

7. No es necesario agregar un `.gitignore` archivo de licencia o para este proyecto de software, por lo que deje esas opciones sin cambios.

8. Haga clic en **Create repository** (Crear repositorio).

## Adición de una página web de inicio

Tu proyecto de software se convertirá en una pequeña página web, así que agrega un archivo `index.html` para albergar su contenido.

1. En la página principal del repositorio encima de `stargazers-log` la lista de archivos, haga clic en **<svg version="1.1" width="16" height="16" viewBox="0 0 16 16" class="octicon octicon-plus" aria-label="plus" role="img"><path d="M7.75 2a.75.75 0 0 1 .75.75V7h4.25a.75.75 0 0 1 0 1.5H8.5v4.25a.75.75 0 0 1-1.5 0V8.5H2.75a.75.75 0 0 1 0-1.5H7V2.75A.75.75 0 0 1 7.75 2Z"></path></svg>** y, a continuación, haga clic en **<svg version="1.1" width="16" height="16" viewBox="0 0 16 16" class="octicon octicon-plus" aria-label="plus" role="img"><path d="M7.75 2a.75.75 0 0 1 .75.75V7h4.25a.75.75 0 0 1 0 1.5H8.5v4.25a.75.75 0 0 1-1.5 0V8.5H2.75a.75.75 0 0 1 0-1.5H7V2.75A.75.75 0 0 1 7.75 2Z"></path></svg> Crear nuevo archivo**.

2. En el campo del nombre de archivo, escriba `index.html`.

3. En el editor de archivos, agregue el siguiente contenido de inicio.

   ```html copy
   <!DOCTYPE html>
   <html lang="en">
     <head>
       <meta charset="utf-8">
       <title>Stargazers log</title>
     </head>
     <body>
       <h1>Stargazers log</h1>
       <p>A log of the repositories I've starred.</p>
     </body>
   </html>
   ```

4. Haga clic en **Commit changes** (Confirmar cambios).

5. En el cuadro de diálogo que se abre, mantenga la opción predeterminada para confirmar directamente en la `main` rama y, a continuación, haga clic en **Confirmar cambios**.
